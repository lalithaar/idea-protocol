# The Idea Protocol

> **v0.0.0 — Draft**

A set of plain-language "idea licenses" that let individuals, students, and collaborators share early-stage ideas safely — without NDAs or awkwardness.

---

## 🌱 What is this?

The **Idea Protocol** is a lightweight framework that provides social and moral clarity when sharing ideas.  
Each license describes *how* an idea may be discussed, reused, or developed — in human terms, not legal jargon.

This project aims to make idea sharing as natural and transparent as choosing an open-source license.

---

## 🧩 Available Licenses (Draft v0.0.1)

| Code | Name | Summary |
|------|------|----------|
| **ICN** | *Idea Commons Notice* | Shared openly for discussion and inspiration, attribution expected. |
| **IRL** | *Idea Review License* | Shared privately for feedback; reuse requires consent. |
| **CRL** | *Collaborative Research License* | Shared within a team; co-ownership assumed unless otherwise agreed. |
| **OIL** | *Open Idea License* | Anyone may build on it, but attribution required. |

Each license is written to be **clear, human-readable, and respectful** — setting expectations rather than enforcing law.

---

## 💡 Example Usage

In an email footer:
`Discussion of attached idea is subject to the Idea Protocol: IRL`
In a project README:
`Shared under the Idea Protocol — Open Idea License (OIL v1.0)`


---

## 🤍 Why This Exists

Because not every idea is ready for lawyers.  
And because trust shouldn't need to feel awkward.
